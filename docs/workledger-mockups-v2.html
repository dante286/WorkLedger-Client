03 — Implementation Notes for New UI Patterns
Project Panel Header
New component above the task list. Shows:
· proj.name in Manrope 700 16px
· Task count + weekly total in DM Mono 10px
· Running timer in DM Mono 500 26px teal (only when active)
· Weekly total should recalculate from time entries where entry.date >= week_start
Running Task Visual Hierarchy
Active/running task card gets elevated treatment:
· Teal left border + subtle teal bg fill
· Task name full opacity, timer value in teal
· Checkbox border-color teal
· All icons at full opacity

Inactive tasks: opacity: 0.75 + muted icon colors
Time Entry Rows
Indented under parent task (36px left padding).
DM Mono 11px for date/range — matches the data-display font rule.
Duration right-aligned, muted.
Delete X uses #f87171 at 40% opacity until hover.
No border between entries — tight gap spacing creates the list rhythm.
