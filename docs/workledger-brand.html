02 — Color System

Color Palette

Built around a cool slate-navy foundation with teal as the single functional accent. Teal signals activity, timers, and CTAs — never decorative. Amber is reserved exclusively for warnings (timer conflicts, sync errors). Red for destructive actions only.

04 — Typography

Type Scale

Three typefaces with distinct roles. Manrope for headings and the wordmark — geometric, confident. DM Sans for UI body text — clean and readable at small sizes. DM Mono for all time values, hex codes, and data — monospaced to prevent layout shift as numbers update.
